# Pokémon CrystalBlue Version

This is a modified version of the decompilation of English Pokémon FireRed and LeafGreen by [pret](https://pret.github.io/).

Current method to build the correct version, is to build the FireRed Rev1 version using `make firered_rev1`.

To set up the repository, see [INSTALL.md](INSTALL.md). To view the changes done in this repository, see [CHANGELOG.md](CHANGELOG.md)
